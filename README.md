# Marble Temple Match

一个可直接在浏览器运行的祖玛风格消除小游戏。

## 玩法

- 点击画布发射当前球，插入球链。
- 三个或更多相同颜色相连会消除。
- 相同颜色越多，分数按平方增长，并追加连消奖励。
- 普通球链里会随机出现技能球，消除后补充技能次数。
- 右侧可选择 6 种颜色，并用 RGB 或 YUV 方式调节色板。
- 共 3 关，关卡越高球链速度和长度越高。

## 技能

- 暂停倒计时：暂停关卡计时 8 秒。
- 回退队列：让所有球沿路径按顺序后退 4 秒。
- 相邻消除：以鼠标位置附近的球为中心消除相邻 3 个球。

## 运行

直接打开 `index.html`，或用任意静态服务器托管本目录。
